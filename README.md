# Stockly Picker

Stockly Picker is an AI-assisted stock screening and ranking tool that scores watchlist tickers daily across seven independent panelist lenses — momentum, valuation, disruption, earnings, sector-relative strength, AI networking, and technical setup — and surfaces the highest-conviction names each session.

**[View today's report →](https://gylesy.github.io/stockly-picker/)**

---

This repository contains generated output only — the built `index.html` report published here each day. Source code, scoring algorithms, and panelist configuration are not included. A single-commit deploy pattern is used so the repository stays small: only today's report is kept, not a full archive.
